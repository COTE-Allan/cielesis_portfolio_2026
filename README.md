# Cielesis Portfolio 2026

My portfolio, made to feel like a mid-2000s console menu. It's inspired by the Wii and the Frutiger Aero look: glossy glass, bubbles, sky-blue gradients.

Each project gets its own tile in a grid, and you open it the way you'd launch a game. You can drag the tiles around, sort them into folders and collect badges.

Built with React, Vite and Sass.
